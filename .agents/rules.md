# Antigravity Agent Rules

## Tool Usage
- NEVER run terminal commands like `cat`, `grep`, `Select-String`, or `ls` to view or search files. 
- ALWAYS use the native Antigravity tools: `view_file`, `grep_search`, `list_dir`. 
- Using native tools avoids triggering Human-in-the-Loop (HITL) approval popups and improves execution speed and reliability.

## Smart Execution
- Minimize unnecessary interruptions.
- Prefer automated, built-in tools over manual terminal commands whenever possible.
