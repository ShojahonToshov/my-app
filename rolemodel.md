# Elara Design System - Rolemodel

Этот документ служит единым источником правки (Single Source of Truth) для визуального стиля новых страниц (на основе `/design`). 
Все новые страницы должны опираться на этот документ для обеспечения 100% консистентности.

## 1. Типографика (Typography)
- **Основной шрифт**: `Outfit` (подключается через `next/font/google`).
- **Размеры текста**:
  - Заголовки (H1): `text-3xl` (30px), `font-bold`, `tracking-tight`
  - Подзаголовки / описания: `text-[14px]` или `text-[15px]`, `font-medium`
  - Кнопки / табы: `text-[14px]` или `text-[15px]`, `font-bold`
  - Лейблы чекбоксов / мелкий текст: `text-[14px]`, `font-medium`

## 2. Цветовая палитра (Colors)
Базовые цвета интерфейса:
- **Фон страницы (Background)**: `#D8DADC` (общий) или `#F3F4F4` (для светлых блоков).
- **Основной текст (Primary Text)**: `#0B0C0D` (почти черный).
- **Второстепенный текст (Muted Text)**: `#8D9195` (серый).
- **Акценты (Accent / Brand)**: `#151719` (темно-серый/черный для кнопок).
- **Цвета инпутов (Inputs)**:
  - Фон инпута: `#F3F4F4` или `#f5f5f4` (как в `/login`).
  - Рамка инпута: `#dcdcda` (default), `#0B0C0D` (focus).
  - Текст инпута: `#0B0C0D` (default), `#8D9195` (placeholder).

## 3. Скругления (Border Radiuses)
Строго соблюдать следующие размеры скруглений:
- **Кнопки (Submit)**: `rounded-2xl` (или `rounded-xl` как в /login).
- **Табы переключения**: `rounded-xl`.
- **Инпуты (Поля ввода)**: `rounded-xl` (как в `/login`!).
- **Карточки (Cards/Модалки)**: `rounded-[32px]` (большие скругления для блоков) или `rounded-3xl`.
- **Чекбоксы**: `rounded-md`.

## 4. Эффекты (Effects)
- **Тени карточек**: `shadow-[0_20px_60px_-15px_rgba(0,0,0,0.05)]`
- **Blur эффекты**: Для плашек используется `backdrop-blur-3xl` и `bg-white/80`.
- **Фокус на инпутах**: Использовать `focus:ring` или стилизованный `border` без системного синего outline. (ВАЖНО: Подавлять системный Chrome Autofill `:-webkit-autofill`).
- **Глобальный Шум (Noise)**: Поверх фона накладывается SVG паттерн `fractalNoise` (opacity `0.03`).
- **Свечения (Orbs)**: Для украшения фона используются `blur-[100px]` элементы.

## 5. Структура форм (на основе /login)
Новые формы (логин, регистрация) берут **структуру** из `/login`, но визуально подстраиваются под дизайн-систему:
- Иконки внутри полей (слева).
- Кнопка показать/скрыть пароль (справа).
- Анимации через `framer-motion` (пружинные переходы `type: "spring"`).
